# Нативное ядро LONG Virtual Camera

Этот каталог содержит единственное нативное ядро Android, производное от
CamReplace и дополненное проверенными механизмами ReCam. Локальные файлы и
аутентифицированный OBS/RTMP являются входными адаптерами одной цепочки
MediaCodec → защищённое кольцо кадров → cameraserver/audioserver hook.

Пользовательский продукт — только LSPosed APK из `../../lsposed-module`.
Windows-приложения, Python UI и второй движок удалены. Камера, фотография и
явно включаемый виртуальный микрофон — независимые lease одной сессии; при
выключенном микрофоне используется штатный микрофон телефона.

Подробности: [главный README](../../README.md), [архитектура](../../docs/ARCHITECTURE.md)
и [аудит исходных проектов](../../docs/UPSTREAM-CODE-AUDIT.md).

Используйте программу только на собственных или явно разрешённых устройствах.
