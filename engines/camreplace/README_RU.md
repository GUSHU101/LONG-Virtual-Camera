# Нативное ядро LONG Virtual Camera

Этот каталог содержит нативное ядро Windows/Android, производное от
CamReplace. Адаптеры источников, правила владения кадрами, проверки и жизненный
цикл из ReCam встроены в тот же процесс; отдельного пользовательского выбора
движка нет.

Сборка создаёт один `LONG-Virtual-Camera.exe`. OBS, тестовый шаблон,
файл/URL и DirectShow-камера поступают в общий RTMP/H.264 конвейер. Подмена
камеры, фотографии и явно включаемого виртуального микрофона — совместимые
функции одной сессии устройства.

Запускайте корневой `build.bat`. Отсутствующий или пустой ADB, runtime,
Android payload либо ресурс интерфейса останавливает release-сборку.

Подробности: [главный README](../../README.md), [архитектура](../../docs/ARCHITECTURE.md)
и [аудит исходных проектов](../../docs/UPSTREAM-CODE-AUDIT.md).

Используйте программу только на собственных или явно разрешённых устройствах.
