# LONG Virtual Camera 全局代码审计

审计基线为 `main` 的 `ac8eb74`，共 205 个 Git 跟踪文件。清点了当前 Android 产品的入口、构建目标和测试，并沿 APK 控制层、Root 生命周期、媒体生产者、共享缓冲区、系统服务消费者与发布流程检查数据和状态边界。第三方依赖检查到集成、构建和调用边界。两份上游项目的固定提交和取舍记录见[上游源码审计](UPSTREAM-CODE-AUDIT.md)。

## 已确认并修复

| 优先级 | 路径 | 问题与修复 |
| --- | --- | --- |
| 高 | 本地视频解码 | 裁剪参数在边界检查前参与有符号计算。连续格式变动还可能继承上一个格式遗留的 stride 或 slice height。现在先核验尺寸、裁剪、色彩格式和容量，按合法布局只复制实际需要的字节，单帧复制上限为 96 MiB。 |
| 高 | 本地兼容传输认证 | 票据验证入口缺少签名缓冲区检查。接收失败可留下上一次输出，Finished 校验失败还会提前更新接收序列。现在先验证缓冲区和完整证明，失败时清除明文，成功后才更新状态。 |
| 高 | OBS 和 TCP 连接生命周期 | 监听描述符在 `poll` 报告就绪后仍可能阻塞在 `accept`。RTMP 对端断线也可能在写入时触发 `SIGPIPE`。监听改为非阻塞，连接保留阻塞 I/O 及原超时设置，RTMP 的写入错误由调用方处理。 |
| 中 | APK 正式发布 | 重复发布会覆盖既有正式资产。创建发布前改为核验制品摘要并拒绝重复版本。已有标签必须指向构建提交。手动开发包继续走独立签名和制品路径。 |

## 其他执行路径

| 路径 | 审计结果与验证边界 |
| --- | --- |
| APK 和 LSPosed | 当前静态作用域是 `system`，APK 检查 `system_server` 的作用域凭据。Native 进程仍由 Root 控制器管理。作用域状态、载荷校验和实际消费帧属于不同验证层。 |
| Root 安装和恢复 | APK 内嵌清单校验长度和 SHA-256。安装脚本在写入后复核载荷，再解除回滚处理。现有恢复故障注入覆盖撤销共享状态、停止 feeder、清理相机与音频服务。断电或 SIGKILL 可跳过 shell 回滚，还需要验证下一次启动如何收敛。 |
| 媒体配置 | 文件按摘要命名，配置文件通过同目录原子重命名提交。进程内互斥覆盖单个 APK 实例。正式版和开发版同时写入同一 Root 配置时仍存在读改写冲突，也可能出现对旧媒体的过早清理。 |
| 视频共享内存与消费者 | 检查三槽 pin、提交计数、旧帧退回、YUV 目标跨度和方向适配。软件测试覆盖共享内存、几何及调度检查。私有相机 ABI、厂商缓冲区布局及多路会话要按设备验证。 |
| 音频与麦克风 | 麦克风默认关闭，启用时需要单独租约。PCM 版本、格式和欠载有独立检查。恢复脚本模拟不能证明所有录音客户端在停用后均已回到实体麦克风。 |
| OBS | 默认监听回环地址。显式开放 LAN 时通过发布密钥验证，但 RTMP 传输为明文。本地兼容传输的握手与 OBS 是两个独立的协议边界。 |

## 验证

- 桌面原生用例覆盖签名长度、无效枚举、解密失败的输出清理、错误 Finished 未改变重放窗口、合法空载荷、极端裁剪及超限存储。
- Quality 工作流包含真实回环 socket 的连接与取消测试，以及既有的控制器故障注入、共享内存、YUV、PCM、Gradle lint 和 APK 完整性检查。
- 正式发布脚本使用模拟仓库检查重复发布、标签提交不匹配、摘要不匹配和新版本路径。
- 稳定性仍需用真机的本地视频、OBS 断线重连、连续启停、并发相机客户端及麦克风恢复分别验收。

## Pixel 5 真机复查

在 Android 14 上确认了本地视频 feeder、共享帧发布和当前 `cameraserver` hook 均在线。Google 相机同时提交了 `1024×768` 的 YUV 预览和 `4032×3024` 的 RAW10。在第 120 次回调的统计点，记录了 59 次已完成的预览写入、60 次不支持格式直通，原始队列调用报错为 0。预览写入成功不能证明 RAW10 或由它生成的照片已替换。

| 路径 | 复查发现与处理 |
| --- | --- |
| JPEG 输出 | 旧编码器可能在容量不足时已覆盖原始照片。改为在临时内存完成编码，确认目标是 Camera3 JPEG BLOB 后才提交，同时校验长度并初始化尾标。JPEG APP segments 不作为照片处理。 |
| YUV 输出 | 旧计数在固定共享帧和完成写入前增加。现在校验尺寸、行距和裁剪，复核租约和共享通道，在写入并解锁成功后计数。 |
| 状态与诊断 | 面板读取当前 `cameraserver` 的结构化统计，分别显示 YUV、JPEG 与 RAW10 直通。累计值用于判断服务端写入，无法证明客户端选择了对应输出流。 |
| Root 生命周期 | 原控制器把历史连接事件中的应用也作为当前会话强停和重开。现只读取活动客户端列表。照片开关在媒体链路就绪后才写入启用标记，失败走回滚。 |

JPEG 回归用例在 Pixel 5 上运行，覆盖超容量、截断输入、非 JPEG BLOB 字节不变和正常提交。新版载荷的实际拍照输出、OBS 断线重连、麦克风停用后实体录音及其他固件仍需端到端复测。
