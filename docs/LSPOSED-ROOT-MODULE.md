# LSPosed 与 Root 控制面板

安装 Android ARM64 APK 后，在兼容 libxposed API 102 的 LSPosed 中启用模块，推荐作用域为 `system`。按管理器提示重启手机，然后在 App 内检查框架与 Root 状态，校验并安装载荷。

LSPosed 在 `system_server` 激活模块入口。Root 控制器把相机载荷加载到独立的 `cameraserver` 进程，载荷通过 Camera3 输出缓冲区替换画面。控制器核对进程映射和与当前 PID 一致的就绪标记后才报告 hook 就绪。普通 App 无需单独加入作用域。

- 全局摄像头和照片功能分别开关，共用同一个视频来源。照片开关仅对应受支持的 JPEG 输出。
- 虚拟麦克风默认关闭。需要替换时手动选择音频输入，再开启麦克风开关。关闭后使用手机原生麦克风。
- OBS 默认走手机回环，USB 连接使用 `adb forward tcp:1935 tcp:1935`，OBS 填 `rtmp://127.0.0.1:1935/live`。局域网监听由面板单独授权。兼容 H.264 和可选 AAC，连接设置及本次生成的推流密钥在手机显示。
- 面板退出后控制器管理的运行状态仍可能处于开启。结束时使用“停止全部并恢复系统服务”，检查结果提示。

状态中的开关、feeder、hook 和媒体通道分别表示用户选择、进程就绪、系统接入和媒体发布。已监听的 OBS 不代表正在收帧。

开发签名 APK 由 CI 生成，正式发布需使用稳定签名。旧桌面产物由对应历史版本维护。模块涉及系统服务，固件适配请在授权设备验证。
